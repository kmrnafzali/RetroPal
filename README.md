# Lesen

Eine kleine EPUB-Lese-App für iPhone (SwiftUI):

- Bücherregal mit Covern, eigenen Regalen und „Weiterlesen"
- Reader mit echtem Seitenumblättern (Page Curl) und Lesezeichen
- Einzelseite auf dem Außendisplay, Doppelseite auf dem Innendisplay (iPhone Duo)
- Schriftgröße und Themes (Papier, Sepia, Nacht)

## Installieren

1. Unter *Releases* die Datei `Lesen.ipa` laden (wird bei jedem Push automatisch gebaut).
2. Mit AltStore installieren.

Gebaut wird mit XcodeGen (`project.yml`) auf einem GitHub-macOS-Runner.
